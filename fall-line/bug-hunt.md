# Fall Line Bug Hunt

This folder holds Fall Line, an open-mountain snowboarding game in one file, `index.html`. Open it in a browser to play. three.js loads from a CDN.

Players say the game has playability bugs. Your job is to find them.

Review the code and play-test the game, then write `BUGS.md` listing every bug you find. For each bug, give:

- **What the player sees.**
- **How to make it happen.**
- **The cause in the code,** with line numbers.
- **How badly it hurts play:** high, medium or low.
- **How you know:** you reproduced it in the browser, or you only found it in the code.

Don't fix anything, and don't change `index.html`. The report is the whole job.
