# Build a waitlist landing page for Fernway

Fernway is a pre-launch startup making onboarding software for HR teams at companies with 50 to 1,000 employees. It runs a new hire's first 90 days, from signed offer to settled in. Build its landing page, with a waitlist for the private beta.

The logo is in `brand/`. Everything else is up to you.

## Rules

- Fernway has no customers, testimonials or metrics yet. Don't invent any.
- The waitlist form asks for a work email (required) and company size (required). There's no backend: save signups to `localStorage` under the key `fernway-waitlist`.
- Don't generate images with AI. You can download freely licensed images (credit them in `CREDITS.md`) or make your own graphics.
- Build a static site with `index.html` at the root of this folder. It must work when served with `python3 -m http.server`.
- Work only inside this folder. If you start a server, stop it by its PID or port, never by process name.
- Nobody will answer questions while you work, so make your own decisions and finish the job.

When you're done, write `NOTES.md` saying what design direction you chose and which skills you used, if any. Then commit your work with git.
